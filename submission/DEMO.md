# RailSync Demo

## Live Interactive Demo

[https://rail-sync-eosin.vercel.app](https://rail-sync-eosin.vercel.app)

The deployed application is RailSync's working interactive demo. Reviewers can use it to select a corridor, run the optimizer, inspect the plan and analysis, and exercise disruption recovery.

## Reviewer Walkthrough

1. Explain the maintenance-block planning problem.
2. Open RailSync.
3. Select a corridor.
4. Review train occupancy and maintenance demand.
5. Run the optimizer.
6. Show the integrated block plan.
7. Open Analysis.
8. Show baseline versus RailSync results.
9. Open Scenario Lab.
10. Trigger a disruption and demonstrate reoptimization.

The larger videos under `frontend/public/videos/` are interface background media, not a narrated product demonstration.
